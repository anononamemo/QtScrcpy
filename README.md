# QtScrcpy

![license](https://img.shields.io/badge/license-Apache2.0-blue.svg)
![release](https://img.shields.io/github/v/release/barry-ran/QtScrcpy.svg)

Зеркалирование и управление Android-устройством в реальном времени через USB или Wi-Fi. Не требует root-прав.

Поддерживает три платформы: **GNU/Linux**, **Windows** и **macOS**.

Основные преимущества:

 - **Лёгкость** (отображает только экран устройства)
 - **Производительность** (30~60 кадров/с)
 - **Качество** (1920x1080 и выше)
 - **Низкая задержка** ([35~70 мс][lowlatency])
 - **Быстрый запуск** (первый кадр примерно через 1 секунду)
 - **Ненавязчивость** (на устройство ничего не устанавливается)

[lowlatency]: https://github.com/Genymobile/scrcpy/pull/646

## Назначение клавиш

Вы можете написать свой скрипт для привязки клавиш клавиатуры и мыши к нажатиям на экране телефона. [Здесь](docs/KeyMapDes.md) описаны правила написания скриптов.

По умолчанию доступны скрипты для TikTok и некоторых игр. После включения можно играть с клавиатуры и мыши. Пример раскладки для PUBG Mobile:

![game](screenshot/game.png)

Инструкция по добавлению своей раскладки:

- Напишите скрипт и поместите его в папку `keymap`
- Нажмите «обновить скрипты», чтобы он появился в списке
- Выберите свой скрипт
- Подключите телефон, запустите сервис и нажмите «применить»
- Нажмите клавишу `~` (SwitchKey) для переключения в режим назначенных клавиш
- Нажмите `~` снова для возврата в обычный режим

- Поддержка мультитача

## Запуск

Подключите Android-устройство к компьютеру, запустите программу и нажмите «USB подключение» или «Wi-Fi подключение».

### Беспроводное подключение (телефон и ПК должны быть в одной сети):

1. Включите отладку по USB в настройках разработчика на Android-устройстве
2. Подключите устройство к компьютеру по USB
3. Нажмите «обновить» — появится серийный номер устройства
4. Нажмите «получить IP»
5. Нажмите «запустить adbd»
6. Нажмите «подключить по Wi-Fi»
7. Снова нажмите «обновить» — появится устройство с IP-адресом. Выберите его.
8. Нажмите «подключить»

После запуска adbd USB-кабель можно отключить.

## Описание кнопок интерфейса

- **Настройки** — параметры перед запуском сервиса:
    - Битрейт, разрешение, формат записи, путь сохранения видео
    - Фоновая запись — экран устройства не отображается, только запись
    - Поверх всех окон — окно видео остаётся на переднем плане
    - Выключить экран — экран устройства гаснет для экономии энергии
    - Обратное подключение — режим запуска. Снимите галочку при ошибке `more than one device`
- **Обновить** — обновить список подключённых устройств
- **Подключить** — подключиться к Android-устройству
- **Отключить** — отключиться от устройства
- **Отключить всё** — отключить все подключённые устройства
- **Получить IP** — получить IP-адрес устройства
- **Запустить adbd** — запустить adbd на устройстве (обязательно перед Wi-Fi подключением)
- **Wi-Fi подключение** — подключиться по Wi-Fi
- **Wi-Fi отключение** — отключить Wi-Fi соединение

## Основные функции

- Отображение экрана Android-устройства в реальном времени
- Управление устройством с помощью мыши и клавиатуры
- Запись экрана
- Скриншоты (PNG)
- Беспроводное подключение
- Подключение нескольких устройств одновременно
- Полноэкранный режим
- Поверх всех окон
- Установка APK — перетащите файл в окно видео
- Передача файлов — перетащите файл в окно видео
- Фоновая запись — только запись, без отображения
- Буфер обмена:
    - `Ctrl + C` — копировать буфер устройства на компьютер
    - `Ctrl + Shift + V` — отправить буфер компьютера на устройство
    - `Ctrl + V` — вставить текст из буфера компьютера
- Групповое управление
- Трансляция звука на компьютер (на основе [sndcpy](https://github.com/rom1v/sndcpy), Android 10+)

## Сборка

Все зависимости включены, сборка выполняется просто.

### QtScrcpy

1. Установите среду разработки Qt (версия 5.12 и выше, на Windows — MSVC 2019). Можно использовать официальный установщик или [aqt](https://github.com/miurahr/aqtinstall).
2. Клонируйте проект: `git clone --recurse-submodules git@github.com:anononamemo/QtScrcpy.git`
3. **Windows**: откройте CMakeLists.txt в QtCreator и соберите Release
4. **Linux**: выполните `./ci/linux/build_for_linux.sh "Release"`
5. **macOS**: откройте CMakeLists.txt в QtCreator или соберите через CMake

Результат сборки: `output/<архитектура>/Release`

### Scrcpy-Server

1. Настройте среду разработки Android
2. Откройте серверный проект в корне репозитория в Android Studio
3. Скомпилируйте APK, переименуйте в `scrcpy-server` и замените файл в `QtScrcpy/QtScrcpyCore/src/third_party/scrcpy-server`
